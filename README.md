# Claude Usage Bar

A small macOS menu bar app that shows how much of your Claude subscription quota is left:

```
5h 72% · 7d 39%
```

- **5h**: what's left of the current 5-hour session window.
- **7d**: what's left of the weekly limit (all models).

A number turns **light orange** below 25% left and **light red** below 10%. A `⚠︎` means the last
refresh failed and the numbers may be stale.

Click the item for details:

- each limit reported by Claude (session, weekly, and any per-model weekly caps such as Opus), with a
  usage bar, % used, and when it resets ("Resets in 3h 44m · 21:59")
- the signed-in account and organization, and when the data was last updated
- Refresh, a link to claude.ai's usage page, *Launch at login*, and a gear menu (switch account,
  sign out, quit)

Usage is refreshed every 3 minutes, when you open the panel (if the data is more than a minute old),
after the Mac wakes, and just after a limit resets.

## Requirements

- macOS 15 or later
- Swift 6 toolchain. The Xcode Command Line Tools are enough (`xcode-select --install`); full Xcode
  isn't required.
- A Claude Pro/Max (subscription) account

## Build and install

```sh
./build.sh            # builds "build/Claude Usage Bar.app"
./build.sh install    # builds, copies to /Applications, (re)launches it
```

`build.sh` runs `swift build -c release`, wraps the binary in an `.app` bundle with
`Resources/Info.plist` (a menu-bar-only app, no Dock icon) and signs it ad hoc.

The app isn't notarized. Since you build it locally, Gatekeeper doesn't block it.

To start it automatically, tick **Launch at login** in the panel. This works best with the app in
`/Applications`.

## Sign in

Click the menu bar item → **Sign in with Claude…**. Your default browser opens Claude's authorization
page; approve it and the tab will tell you it can be closed. The app is then signed in.

This is the same OAuth flow Claude Code and oh-my-pi use: PKCE, with a one-shot listener on
`http://localhost:<random port>/callback` that only accepts loopback connections. Only the
`user:profile` scope is requested, which is enough to read usage and gives no access to your
conversations or to inference.

Claude ends these sign-ins about 30 days after login. When that happens the app signs out and asks
you to sign in again.

## How it works

| What | Where |
|---|---|
| Usage data | `GET https://api.anthropic.com/api/oauth/usage`, the endpoint behind Claude Code's `/usage` |
| Token exchange / refresh | `POST https://api.anthropic.com/v1/oauth/token`; refresh tokens rotate and are re-saved |
| Credentials | login keychain, service `ClaudeUsageBar`, account `oauth` |

Credentials are read and written through `/usr/bin/security`, as Claude Code does. Items created by
that Apple-signed tool don't trigger a keychain password prompt when the ad-hoc signed app is rebuilt.
The tradeoff: any process running as your user can read the item through `security` without a prompt.

### Caveats

- The usage endpoint and OAuth client are Claude Code's, not a public API. Anthropic can change
  them at any time.
- Requests identify as the Claude Code CLI (`User-Agent: claude-cli/…`), because the usage
  endpoint heavily rate-limits unknown clients. After an HTTP 429 the app waits at least 5 minutes.

## Project layout

```
Package.swift                      SwiftPM manifest (one executable target)
build.sh                           build + bundle + sign (+ install)
Resources/Info.plist               bundle metadata (LSUIElement: menu bar only)
Resources/AppIcon.icns             app icon, generated by scripts/make-icon.swift
scripts/make-icon.swift            draws the icon and builds the .icns (swift scripts/make-icon.swift)
Sources/ClaudeUsageBar/
  App.swift                        entry point, NSStatusItem with colored title, popover
  UsagePopover.swift               SwiftUI detail panel
  UsageModel.swift                 state, polling, token refresh, sign-in/out
  UsageLevel.swift                 25% / 10% thresholds and colors
  ClaudeAPI.swift                  usage request and response parsing
  ClaudeOAuth.swift                browser OAuth (PKCE + loopback listener), token refresh
  Keychain.swift                   credential storage via /usr/bin/security
```

## Uninstall

1. Untick **Launch at login** if enabled, then **Quit** from the gear menu.
2. Remove the app and its stored credentials:

```sh
rm -rf "/Applications/Claude Usage Bar.app"
security delete-generic-password -s ClaudeUsageBar -a oauth
```
